# 🎮 Typing Adventure Game

An interactive, colorful typing game designed to teach and test typing skills, perfect for kids and beginners!

## ✨ Features

- **20 Progressive Levels** - Start easy and advance to expert level
- **Level Selection** - Choose any level to start from
- **Visual Keyboard** - Colorful on-screen keyboard showing key presses in real-time
- **Live Statistics** - Track accuracy and words-per-minute (WPM) as you type
- **Kid-Friendly Design** - Vibrant colors, fun animations, and engaging UI
- **Progress Tracking** - Automatically saves your best scores for each level
- **Responsive Design** - Built with Tailwind CSS for a modern look

## 🎯 Level Progression

- **Levels 1-5**: Home row keys (easy) - Learn the basics
- **Levels 6-10**: Top row added (medium) - Expand your skills  
- **Levels 11-15**: Bottom row added (hard) - Master all letters
- **Levels 16-20**: Numbers & symbols (expert) - Ultimate challenge

## 🚀 Getting Started

Simply open `index.html` in your web browser to start playing!

No installation or build process required - it's pure HTML, CSS, and JavaScript.

## 🎮 How to Play

1. Select a level from the level selection screen
2. Type the characters shown on screen
3. Watch the on-screen keyboard light up as you type
4. Track your accuracy and speed
5. Complete the level to unlock the next one!
